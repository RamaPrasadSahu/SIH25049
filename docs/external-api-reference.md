# External API Reference - Official Documentation Links

This application relies on official documentation from certified API providers:

## 1. Sarvam AI
- **Official Documentation Portal**: [https://docs.sarvam.ai/](https://docs.sarvam.ai/)
- **Authentication**: `api-subscription-key` HTTP header
- **Speech-to-Text Endpoint**: `POST https://api.sarvam.ai/speech-to-text` (Model: `saaras:v3`)
- **Text-to-Speech Endpoint**: `POST https://api.sarvam.ai/text-to-speech` (Model: `bulbul:v1`)
- **Translate Endpoint**: `POST https://api.sarvam.ai/translate` (Model: `mayura:v1`)

## 2. Google Gemini API
- **Official Documentation**: [https://ai.google.dev/docs](https://ai.google.dev/docs)
- **Model Used**: `gemini-1.5-flash`
- **Authentication**: API key parameter (`?key=...`)

## 3. Firebase Documentation
- **Firebase Auth**: [https://firebase.google.com/docs/auth](https://firebase.google.com/docs/auth)
- **Cloud Firestore**: [https://firebase.google.com/docs/firestore](https://firebase.google.com/docs/firestore)
- **Cloud Functions (v2)**: [https://firebase.google.com/docs/functions](https://firebase.google.com/docs/functions)
